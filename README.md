🏦 Indian Banking Transactions Analysis Using Excel

📌 Project Overview

This project analyzes Indian banking transaction data using Microsoft Excel to understand transaction patterns, customer activity, payment modes, transaction status, regional performance, branch activity, and potential fraudulent transactions.

The project converts raw banking transaction data into meaningful KPIs, visualizations, business insights, and recommendations through Excel data cleaning, Pivot Tables, formulas, charts, and dashboarding.

⸻

🎯 Business Objective

The main objectives of this project are:

* Analyze transaction trends across regions and branches.
* Identify transaction patterns and potentially fraud-prone branches.
* Analyze digital and branch/payment channels.
* Track transaction status such as Completed, Failed, Reversed, and Pending.
* Analyze deposits, withdrawals, transfers, and other transaction types.
* Build an interactive Excel dashboard for business reporting.

🔍 Key Insights

🌎 Regional Analysis

* The North region recorded the highest transaction volume with 110 transactions.
* The East region recorded the lowest transaction volume with 94 transactions.

💰 Transaction Analysis

* The dataset contains 500 transactions.
* Total transaction amount is approximately ₹9.39 crore.
* Average transaction amount is approximately ₹1.88 lakh.

🔄 Transaction Type

* Deposit was the most frequent transaction type with 140 transactions.
* Online Transfer recorded 136 transactions.
* Withdrawal recorded 116 transactions.
* Cheque recorded 108 transactions.

💳 Payment Mode

* Debit Card was the most frequently used payment mode with 128 transactions.
* Credit Card recorded 100 transactions.
* Cash recorded 98 transactions.
* UPI recorded 94 transactions.
* Net Banking recorded 80 transactions.

📌 Transaction Status

* 434 transactions (86.8%) were completed.
* 26 transactions (5.2%) failed.
* 21 transactions (4.2%) were reversed.
* 19 transactions (3.8%) were pending.

🚨 Fraud Analysis

* 13 transactions were flagged as potentially fraudulent.
* The fraud rate was 2.6% of total transactions.
* Bhopal Branch recorded the highest number of fraud-flagged transactions with 3 cases.

🏢 Branch Analysis

* Indore and Chennai branches recorded the highest transaction volume with 28 transactions each.
* Mumbai Branch recorded the lowest transaction volume with 12 transactions.

📅 Monthly Analysis

* November 2023 recorded the highest monthly transaction count with 28 transactions.

⸻

💡 Business Recommendations

Based on the analysis:

1. Monitor fraud activity
    * Closely monitor branches with comparatively higher fraud-flagged transactions.
2. Improve failed transaction monitoring
    * Investigate recurring failed transactions to identify operational or payment-channel issues.
3. Optimize payment channels
    * Monitor high-volume payment modes and ensure reliable service availability.
4. Monitor branch performance
    * Compare transaction volumes across branches to identify differences in customer activity.
5. Track transaction status
    * Regularly monitor failed, reversed, and pending transactions to improve transaction completion rates.
